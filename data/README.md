# Deck data

Generated data for the vocabulary deck and Anki export.

| File | Purpose |
|---|---|
| `vocab.json` | Main 1,315-entry deck |
| `vocab.csv`, `vocab.tsv` | Flat exports |
| `anki_notes.tsv` | 12-field Anki import file |
| `Korean_Vocab.apkg` | Ready-made Anki deck |
| `review_changes.csv` | Manual review corrections |
| `overrides.json` | Word/meaning pipeline overrides |
| `hanja_overrides.json` | Manual hanja corrections |
| `hanja_trust.json` | Hanja words trusted for display in the app |

Audio lives in `../korean-app/audio/`.
